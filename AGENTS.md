# Repository Guidelines

## Project overview

Base Rollup is an Obsidian plugin that registers a custom Bases view. The view renders query results and writes an aggregate value back to the note that embeds the Base.

## Development

- Source files live in `src/`.
- `src/main.ts` should only contain plugin registration and lifecycle code.
- Keep view rendering logic in `src/RollupBasesView.ts`.
- Keep option definitions and pure helpers in separate modules.
- Run `npm run build` before committing changes.

## Release files

Obsidian loads these files from the plugin root:

- `manifest.json`
- `main.js`
- optional `styles.css` if added later

`main.js` is generated by the build and should be committed for releases.

## Git

- Use focused commits.
- Follow Conventional Commits unless the repository history clearly uses another style.
- Do not use `git add .`; stage only relevant files.
